## "customer_banking"
In the savings_account.py contains the Account class. 
savings account instance, calculates the interest earned based on user input, updates the account balance with the earned interest, and returns the updated balance and interest earned.

The cd_account.py file houses the Account class.
It creates a create_cd_account function that creates a CD account instance, calculate the interest earned based on user input, updates the account balance with the earned interest, and returns the updated balance and interest earned.

The customer_banking.py file contains the create_savings_account and create_cd_account functions that prompt the user to enter the savings and CD account details, call the corresponding functions to calculate the interest earned and update the balances, and finally to display the results.
